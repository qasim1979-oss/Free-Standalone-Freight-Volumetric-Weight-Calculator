## 🚀 Key Features
- **Volumetric & Chargeable Weight:** Compares actual weight against dimensional weight ($L \times W \times H / \text{divisor}$).
- **CBM Volume Calculation:** Computes total cubic meters for sea freight container planning.
- **Customizable Divisors:** Supports 5000 (Air Cargo), 6000 (Courier), and 139 (Imperial) standards.
- **Multi-Box Manifests:** Aggregate multiple box types into a single shipment summary.
- **CSV Manifest Export:** Export itemized freight reports instantly.
- **100% Offline & Secure:** Keep shipment manifests entirely private on your local PC.
